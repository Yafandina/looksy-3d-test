# Тест 3D-фигуры для VK Mini App (Looksy)

Страница: https://yafandina.github.io/looksy-3d-test/

## Что на экране

Реалистичная фигура человека — «Девушка» (топ + шорты) или «Парень» (шорты-боксеры), простое облегающее бельё, расслабленная стойка:
вес на правой ноге, левое колено чуть согнуто, плечи опущены, локти и пальцы слегка согнуты, голова прямо.

- До вещи: фигура, размер РФ по ГОСТ и ростовка (вверху), кнопка «Добавить вещь».
- Вкладка «Вещь»: скрин таблицы размеров из карточки товара (распознавание tesseract.js, rus+eng) или ссылка.
  Маркетплейсы не отдают карточку в браузер (CORS), поэтому основной путь — скрин. Таблицу можно ввести/поправить вручную.
- После вещи: «Ваш размер в этой вещи» (та же функция, что и для ГОСТ: максимум из размеров по груди, талии, бёдрам),
  по зонам «тесно / по фигуре / свободно на N см» (запас: грудь 2, талия 2, живот 4, бёдра 2 см; живот сравнивается с талией размера),
  цветные пояса на теле: красный — тесно, зелёный — по фигуре или свободно.
- Вкладка «Мои мерки»: девушка — рост, грудь, под грудью, талия, живот, бёдра; парень — рост, грудь, талия, живот, бёдра.
- Фигура парня (`male.glb`) грузится только при нажатии «Парень».

Встроенного платья больше нет.

## Файлы

- `female.glb`, `male.glb` — тело с морфами мерок + глаза, брови, ресницы, волосы; текстуры внутри (кожа 2048 JPEG, остальное WebP).
- `tools/` — скрипты сборки (Python: numpy, scipy, pygltflib, Pillow): `pose.py` — перезапекание позы (LBS по скелету MakeHuman default),
  `build.py` — UV, бельё в текстуре кожи, сглаживание груди под топом, посадка ассетов по MHCLO, упаковка glb;
  `male_rest.py` — мужская база (caucasian-male-young + universal-male-young-*weight из MPFB2), руки вниз, морфы мерок.
  Исходник женского тела — `body.glb` из коммита 146cff6 (в скриптах `body_src.glb`).

## Лицензии ассетов

Все использованные ассеты — CC0 (MakeHuman system assets, пакет makehuman_system_assets_cc0, https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html;
в файлах ассетов: «explicitly released as CC0 in september 2020», правообладатели Data Collection AB, Joel Palmius, Jonas Hauquier):

- базовая сетка hm08, морфы, скелет и веса — MakeHuman/MPFB2 (CC0);
- кожа `young_caucasian_female` (young_lightskinned_female_diffuse.png) и `young_caucasian_male` (young_lightskinned_male_diffuse.png);
- глаза `high-poly` + материал `brown`;
- брови `eyebrow001`, ресницы `eyelashes01` (перекрашены в тёмно-коричневый);
- волосы `ponytail01` (девушка) и `short02` (парень);
- мужские макро-таргеты MPFB2 `caucasian-male-young`, `universal-male-young-averagemuscle-{average,max,min}weight` (CC0, https://github.com/makehumancommunity/mpfb2).

Бельё — не сторонний ассет: нарисовано в текстуре кожи скриптом `build.py`.

## Размерные сетки

- Женская 42–64: http://urban-s.ru/tablica-razmerov (рост 164), те же значения: https://resizes.ru/tablitsa-razmerov-gost/
- Мужская 44–70: https://resizes.ru/tablitsa-razmerov-gost/ («Таблица размеров мужской одежды ГОСТ»). Ростовки для мужчин в источнике нет — показывается просто рост.

## Ограничения

- Морфы мерок — на CPU с пересчётом нормалей при движении ползунков.
- На слабых устройствах (меньше 22 кадр/с 3 секунды подряд) тени выключаются и снижается разрешение.
- У парня морфы мерок откалиброваны по замеру обхватов сетки; на крайних мерках (грудь > ~110) форма тела отстаёт от цифр — посадка считается по цифрам, не по сетке.
- Сетка тела без subdivision (около 14,5 тыс. вершин), чтобы не раздувать файл.
