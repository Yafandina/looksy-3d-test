# Тест 3D-фигуры для VK Mini App (Looksy)

Минимальная страница для проверки, тянет ли телефон 3D-манекен с ползунками мерок внутри VK Mini App.

## Что на странице

- Нейтральный портновский манекен без лица и одежды (процедурная геометрия three.js)
- Вращение пальцем
- Ползунки: рост, обхват груди, обхват талии, обхват бёдер (см)
- Обхваты переводятся в радиус по формуле C / 2π и сразу меняют торс
- Размер РФ и ростовка
- Счётчик «Кадров в секунду»
- Инициализация VK Bridge (`VKWebAppInit`)

## Модель

Манекен собран в браузере из примитивов three.js (`LatheGeometry` для торса, капсулы для рук и ног, сфера для головы). Внешних GLB нет. Код three.js — MIT.
