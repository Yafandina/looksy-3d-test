# Тест 3D-фигуры для VK Mini App (Looksy)

Минимальная страница для проверки 3D-манекена и посадки платья.

## Мерки тела

- Рост
- Обхват груди
- Обхват под грудью
- Обхват талии
- Обхват живота
- Обхват бёдер

Также: размер РФ, ростовка, FPS, VK Bridge, вращение 360°.

## Платье

`dress.glb` — приталенное платье до колена **toigo_halter_dress_knee_length** (MargaretToigo, **CC0**, MakeHuman Community / dress01).
Посадка через MHCLO на базу MakeHuman/MPFB2, руки как у тела (bake скелета).
Размеры платья 42–54 по опубликованной сетке (см. комментарий `SIZE_CHART` в `index.html`).
Текст посадки по зонам: Грудь / Талия / Живот / Бёдра.

Переключатель: «Без одежды» / «В платье».

## Модель тела

`body.glb` — MakeHuman / MPFB2 (**CC0**), женская база, расслабленные руки.
SMPL не используется. three.js — MIT.
