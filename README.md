# Тест 3D-фигуры для VK Mini App (Looksy)

Минимальная страница для проверки, тянет ли телефон 3D-фигуру с ползунками мерок внутри VK Mini App.

## Что на странице

- Женская 3D-фигура, вращение пальцем
- Ползунки: рост, обхват груди, обхват талии, обхват бёдер (см)
- Размер РФ и ростовка по введённым меркам
- Счётчик «Кадров в секунду»
- Инициализация VK Bridge (`VKWebAppInit`)

## Модель

Используется `Michelle.glb` из примеров [three.js](https://github.com/mrdoob/three.js) (ветка r170, `examples/models/gltf/Michelle.glb`).

- Исходник модели: **Mixamo** (Adobe). Использование — по условиям Adobe Mixamo.
- Код three.js распространяется под лицензией **MIT**.

Морф-таргетов у модели нет: пропорции приближены масштабом костей.

## Локальный запуск

```bash
python3 -m http.server 8765
```

Открой `http://127.0.0.1:8765/`.
