# Тест 3D-фигуры для VK Mini App (Looksy)

Страница для проверки манекена, посадки платья и карточки товара (скриншоты с WB/Ozon/Lamoda).

## Фигура

Мерки: рост, грудь, под грудью, талия, живот, бёдра. Размер РФ, ростовка, FPS, VK Bridge, 360°.

`body.glb` — MakeHuman/MPFB2 CC0, расслабленные руки.

## Платье

`dress.glb` — CC0 MakeHuman halter knee (MargaretToigo). Размеры 42–64 (urban-s / ГОСТ-сводка); автоподбор «ваш размер».
Переключатель «Без одежды / В платье». Текст посадки по зонам.

## Карточка товара

Вкладка «Карточка товара»:
- ссылка (проверка; при CORS — просьба загрузить скрины);
- фото товара → вырез квадрата ткани → тайл на платье;
- скрин таблицы размеров → ручное редактирование или OCR (tesseract.js, rus+eng, ленивая загрузка);
- посадка считает по сетке карточки вместо ГОСТ.
