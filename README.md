# Тест 3D-фигуры для VK Mini App (Looksy)

Минимальная страница для проверки 3D-манекена с мерками под одежду.

## Мерки

- Рост
- Обхват груди (объём/проекция груди; MakeHuman cup/point)
- Обхват под грудью (рибкейдж; разница с грудью ≈ размер груди)
- Обхват талии
- Обхват живота (stomach / вынос вперёд)
- Обхват бёдер

Также: размер РФ, ростовка, FPS, VK Bridge, вращение 360°.

## Модель

`body.glb` — MakeHuman / MPFB2 (**CC0**), женская база.
Морфы: breast cup/point, underbust, waist, stomach, hips.
SMPL не используется. three.js — MIT.

Поза рук — расслабленные вдоль тела (лёгкий сгиб локтя), bake из скелета
MakeHuman/MPFB2 default (CC0) со skin weights; морфы сохранены.
